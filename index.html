What is this?

メーター管理を、
シンプルにまとめた。

ポコチャでは毎日のメーター結果（+2 / +1 / ±0 / −1）が
累計されてランクが決まります。
このアプリは、その記録と計算をすべて自動でやってくれます。

+2
上位〜20%
ランクポイント+2
+1
上位20〜40%
ランクポイント+1
±0
中位40〜60%
変動なし
−1
下位40%以下
ランクポイント−1

Features

できること

📝

毎日のメーター結果を記録

+2 / +1 / ±0 / −1 をワンタップで記録。おやチケ・OFF日にも対応しています。一言メモも残せます。

🔢

累計ランクポイントを自動計算

記録した結果から累計ポイントをリアルタイムで計算。ランクアップまであと何ポイントか、ランクダウンまでの余裕も一目でわかります。

📊

過去14日の履歴グラフ

14日分のメーター結果をバーグラフで表示。調子のいい日・悪い日の傾向が視覚的に確認できます。

🏆

ランクアップまでのシナリオ

「+2連続」「+1と+2交互」「+1連続」の3パターンで、ランクアップまでの必要日数を自動で試算します。

⏰

締め時間の設定

13時・22時・24時から選んで設定。締め時間までの残り時間をリアルタイムで表示します。

🎯

E1・D1〜S6 全ランク対応

D帯特有のマイナスリセット特典にも対応。どのランクのライバーさんでも正確に管理できます。

📡

ボーダー参考値の予想

各ランクのボーダー参考値を予想表示。今日どのくらいのスコアを目指せばいいか、目安として確認できます。

📊 過去14日のメーター

Dashboard

今日の状況が
ひと目でわかる

累計ポイント・ランクアップまでの残り・14日間の推移。必要な情報がダッシュボードに全部まとまっています。

  • 累計ポイントをリアルタイムで自動計算
  • ランクアップ・ランクダウンまでの余裕を表示
  • 14日分の結果をグラフで振り返り
  • おやチケ・OFF日も記録に含められる
  • D帯のマイナスリセット特典にも対応

How to Start

使い方は3ステップだけ

1

ブラウザで開く

アプリのDLは不要。URLをブックマークしておけばいつでもすぐアクセスできます。

2

自分のランクと締め時間を選ぶ

E1・D1〜S6から現在のランクを選択。締め時間（13時・22時・24時）も設定します。

3

配信後にメーター結果を記録する

+2 / +1 / ±0 / −1 をタップするだけ。累計ポイントとランクアップまでの日数が自動で更新されます。

今日の配信から、
記録を始めよう。

ブラウザで開くだけ、アプリDL不要、完全無料。
E1・D1からS6まで、すべてのライバーさんに使ってほしい。
